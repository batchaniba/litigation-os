# Intelligence catalogs

Curated, machine-readable legal state for the OS in `internal/src/intelligence/`.

These files are not a second docket. They are the issue graph, claim-element matrices, defense fingerprints, judge doctrine maps, fact propositions, argument snapshots, and dependency recipes the engines query.

Coverage percentages computed from the matrices measure filled slots (allegation / evidence / authority / defense). They are not win probabilities.
