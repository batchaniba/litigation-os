THE HARD RULES — READ THESE BEFORE YOU START
====================================================================

1. NEVER report a case as verified from memory. Open the source. If you cannot
   open it, say "COULD NOT OPEN" and name what you tried. A wrong "verified" is
   worse than an honest gap — this portfolio has already had to track fabricated
   citations as remediation debt.

2. Prefer, in this order: the court's own website (supremecourt.gov,
   cdn.ca9.uscourts.gov, courts.ca.gov), govinfo.gov, CourtListener, Justia,
   FindLaw, Cornell LII, leginfo.legislature.ca.gov, OAL / CDCR rulemaking pages.
   Secondary commentary is a lead, never an answer.

3. Quote exactly, with the page or footnote where the words appear. If you cannot
   confirm a pin against actual reporter pagination, label the pin SECONDARY and
   say what corroborated it.

4. Report holdings, not vibes. For every case: the disposition (affirmed /
   reversed / dismissed), what was actually decided, and what the court expressly
   declined to decide. Published or unpublished. If unpublished, say so.

5. If a source contradicts what this prompt assumes, say so plainly. Contradicting
   the assumption is the most valuable thing you can do. Do not agree to be
   agreeable.

6. Do not draft argument. Do not propose brief language. Verification only.
