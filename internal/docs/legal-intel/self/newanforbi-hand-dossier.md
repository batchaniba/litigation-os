## 8. Rule 41(a)(1)(B) two-dismissal analysis

The rule operates claim-by-claim and defendant-by-defendant: a *second* voluntary dismissal of the same claim against the same defendant acts as an adjudication on the merits. On the current census, the six with-prejudice voluntary dismissals name different defendants each (*Macomber*; *Urrea*; *Maloney*; *Barocio*; *Rojo*; CDCR/Dodd/Noguchi). **No same-defendant pair is identified, so the two-dismissal rule is not triggered on this record.** Caveat: "same claim" analysis is claim-specific, and variant spellings could hide a repeat defendant — re-check before any new voluntary dismissal. Your standing instruction not to voluntarily dismiss Matter 28 is consistent with this analysis.
