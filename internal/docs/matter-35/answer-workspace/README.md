## Strategic controls

1. **Do not disclose the unanswered-paragraph theory.** The answer does not address complaint paragraphs 1–21, 85–86, and 129. Preserve the section 431.20 position and lock the underlying facts through RFAs before alerting Ross.
2. **Do not characterize section 431.30(d) as the wrong subsection.** Subdivision (d) contains the verified-complaint denial rule; subdivision (e) addresses insufficient information or belief.
3. **Prioritize evidence over pleading motion practice.** The video, employee identities, Form Interrogatory 15.1, focused RFAs, and Ross's policies and stop records have more value than a broad demurrer that merely invites amendment.
4. **Do not assume pro se work product.** Plaintiff-generated notes, damages worksheets, and AI drafts are not automatically protected under section 2018.030.
5. **Delete Civil Code section 43.5 from the merchant-privilege discussion.** The relevant statute is Penal Code section 490.5(f).
