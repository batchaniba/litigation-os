## Wiring

1. **Lookup.** Run `--batch controls` first; abort if *Richardson* does not resolve FOUND.

   ```bash
   npm run citations:lookup:matter -- --cites-file internal/docs/citation_sources_matter28_primary.json --out internal/docs/citation_lookup_matter28_primary.json
   ```

   lookup-citations.py --cites-file reads the 'cites' key of this file directly; the rest of the payload is ignored by the script. Run --batch controls first and abort if Richardson does not resolve FOUND.

2. **Overlay.** Fold results into `internal/docs/citation_verification_rounds.json` as `{"citation": "<string>", "status": "VERIFIED | MISCITED | MISCHARACTERIZED | NOT_FOUND", "source": "<where it was read>", "notes": "<holding + pin + URL>", "round": "12-matter28-primary-source"}`.

   verify-citations.py binds a round entry to an indexed authority by normalized citation key, falling back to case-name key. Entries whose citation is not in citation_index.json (Meinhardt, Palomar, Pollock, Goddard, Valvo, ASARCO, Heath, Perez, Medical Marijuana, Esche, Wicklund, Merrill) stay inert until the cite appears in a filed PDF — record them anyway so the status exists before the cite is drafted, which is the whole point of a pre-draft pass.

3. **Rebuild.** `npm run citations:verify && npm run citations:check && npm run generate:readme`

4. **Promote.** legal-intel README rule 5: authorities reach the safe-cite list only after the PDF is opened. A VERIFIED existence result is not promotion. Esche stays in CAUTION_NAMES unless the external read contradicts the MISCHARACTERIZED finding on the record.

### Mapping the returned block back

| Returned STATUS | Ledger effect |
|---|---|
| STATUS: VERIFIED | round entry status VERIFIED (existence only — characterization still needs the holding answer) |
| STATUS: CONTRADICTED | round entry status MISCHARACTERIZED, with the contradiction quoted in notes |
| STATUS: COULD NOT OPEN | no round entry — leave UNVERIFIED and record the attempt in notes |
| STATUS: PARTIALLY VERIFIED | round entry only if existence is settled; otherwise leave UNVERIFIED |
| closing list (2) — what cuts against the plaintiff | goes to the matter card / cluster lock and the CAUTION bucket, not to the ledger |
